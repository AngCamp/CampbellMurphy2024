VERSION 2 RUN ON tm-titan
=========================
Reruns the Allen (ABI) datasets against the version 1 (OSF) data. Keeps the version 1
control and ripple channels, rechooses the sharp wave channel, saves channel metadata
and LFP traces. Two sessions are processed at a time.

All of this is set at the top of run_pipeline.sh (paths, datasets, LFP saving) and in
united_detector_config.yaml (pool sizes, which channels to keep), so no flags are needed.
Copy and paste each block into the terminal on tm-titan.


1. GET THE CODE
---------------
cd /home/caoyut/AngusC/SWR_project_folders/CampbellMurphy2024
git pull origin flipped_depth_correction
cd SWR_Neuropixels_Detector


2. CHECK THE OLD DATA (takes a few seconds, run once)
-----------------------------------------------------
The channel choices are read from the old file names, so each count should be above zero.

OLD=/home/caoyut/AngusC/SWR_project_folders/version_1_OSF_data/CampbellMurphy2025_SWRs_data
find $OLD -maxdepth 5 -type d -name "allen_*_swr_murphylab2024"
find $OLD -type d -name "swrs_session_*" | wc -l
find $OLD -name "probe_*_channel_*_movement_artifacts.csv.gz" | wc -l
find $OLD -name "probe_*_channel_*_putative_swr_events.csv.gz" | wc -l
ls "$(find $OLD -type d -name "swrs_session_*" | head -n 1)"

The first command should list the two Allen dataset folders. If a count is zero, stop and
check the file names printed by the last command before running anything.

The Allen conda environment must exist (create it with Setup/setup_environments.sh if not):

conda env list | grep allensdk_env


3. RUN (inside tmux so it survives a disconnect)
------------------------------------------------
tmux new -s swr_v2
cd /home/caoyut/AngusC/SWR_project_folders/CampbellMurphy2024/SWR_Neuropixels_Detector
./run_pipeline.sh

Detach with Ctrl-b then d. Reattach with: tmux attach -t swr_v2

Output goes to /home/caoyut/AngusC/SWR_project_folders/version_2_data
Raw data is downloaded to /home/caoyut/AngusC/SWR_project_folders/dataset_caches


4. IF IT STOPS
--------------
Run ./run_pipeline.sh again. Finished sessions and probes are skipped, using
pipeline_progress.json in each dataset's output folder.


WHAT THE PLAIN COMMAND IS EQUIVALENT TO
---------------------------------------
./run_pipeline.sh subset abi_visual_coding,abi_visual_behaviour \
    -nv /home/caoyut/AngusC/SWR_project_folders/version_1_OSF_data/CampbellMurphy2025_SWRs_data \
    -k control,ripple -m -s

To run something else, the usual commands still work, for example:
./run_pipeline.sh all              all three datasets, including IBL
./run_pipeline.sh subset ibl       IBL only
SAVE_LFP=false ./run_pipeline.sh   without saving LFP traces
